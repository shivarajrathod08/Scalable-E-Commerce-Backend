# 🛒 Scalable E-Commerce Backend

## 🚀 Project Overview
**Scalable E-Commerce Backend** is a backend application designed to manage products and categories efficiently for an e-commerce platform.  
The system supports **robust product management**, flexible category mapping using **many-to-many relationships**, and scalable RESTful APIs suitable for real-world commerce applications.

The project demonstrates strong backend fundamentals, database design skills, and API-driven architecture.

---

## 🎯 Key Features
- 📦 Product and category management with many-to-many relationships  
- 🔗 RESTful APIs for e-commerce operations  
- 🔍 Fetch products and filter them by category  
- ✏️ Full CRUD operations for products and categories  
- 🗄️ Persistent data storage using MySQL  
- 🧪 Reliable API testing using Postman  

---

## 🛠️ Tech Stack
- **Backend Framework:** Spring Boot  
- **Programming Language:** Java  
- **Database:** MySQL  
- **API Testing:** Postman  
- **Architecture:** RESTful APIs
